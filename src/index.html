اختصارات لوحة المفاتيح

استخدم الاختصارات التالية للتنقل السريع وسماع الأسعار:

Alt + G
الانتقال إلى تبويب الذهب
Alt + S
الانتقال إلى تبويب الفضة
Alt + J
الانتقال إلى تبويب جنيه الذهب
Alt + C
الانتقال إلى تبويب العملات
Alt + R
تحديث الأسعار فورًا
Alt + A
تبديل التحديث التلقائي
Alt + P
فتح الإعدادات (اللون وحجم الخط)
Alt + H
تبديل وضع التباين العالي
Alt + K
فتح هذه النافذة
Esc
