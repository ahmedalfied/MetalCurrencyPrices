# Metal & Currency Prices — أسعار المعادن والعملات مقابل الجنيه المصري

تطبيق سطح مكتب (Electron) يعرض أسعار **الذهب** و**الفضة** و**جنيه الذهب** و**العملات الأجنبية**
مقابل الجنيه المصري (EGP)، مع واجهة رسومية كاملة، أوضاع ألوان متعددة، وأحجام خطوط قابلة للتغيير،
ودعم كامل لإمكانية الوصول (ARIA + اختصارات لوحة المفاتيح).

---

## المميزات

- **أربع تبويبات**: الذهب (بالقيراط) • الفضة • جنيه الذهب • العملات.
- **اختيار حر**: لكل تبويب قائمة اختيار (القيراط / العملة / الوزن) ويُحسب السعر فوريًا.
- **أسعار حية**: تُجلب من مصادر السوق مع بيانات احتياطية عند انقطاع الإنترنت.
- **أوضاع العرض**: فاتح • داكن • أزرق • تباين عالٍ (high-contrast).
- **أحجام خطوط**: صغير • متوسط • كبير • كبير جدًا.
- **تحديث تلقائي** قابل للتحكم في المدة.
- **حفظ الإعدادات** تلقائيًا في مسار بيانات المستخدم.
- **تطبيق رسومي حقيقي (.exe)** بلا نافذة سوداء (console).

### اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
|---------|---------|
| `Alt + G` | تبويب الذهب |
| `Alt + S` | تبويب الفضة |
| `Alt + J` | تبويب جنيه الذهب |
| `Alt + C` | تبويب العملات |
| `Alt + R` | تحديث الأسعار |
| `Alt + A` | تشغيل/إيقاف التحديث التلقائي |
| `Alt + P` | الإعدادات |
| `Alt + K` | المساعدة |
| `Alt + H` | تبديل التباين العالي |
| `Esc` | إغلاق النوافذ المنبثقة |

## متطلبات التشغيل من المصدر

- [Node.js](https://nodejs.org) الإصدار 22 فما فوق.
- [Inno Setup 7](https://jrsoftware.org/isdl.php) (مطلوب فقط لبناء ملف التثبيت).

---

## التشغيل من المصدر (وضع التطوير)

```bat
npm install
npm start
```

أو بالنقر المزدوج على الملف: `start.bat`

---

## بناء التطبيق وملف التثبيت

```bat
:: 1) تثبيت الاعتماديات (مرة واحدة)
npm install

:: 2) بناء تطبيق سطح المكتب الرسومي -> dist\MetalCurrencyPrices-win32-x64\MetalCurrencyPrices.exe
npm run package

:: 3) بناء ملف التثبيت -> Output\MetalCurrencyPrices-Setup.exe
npm run installer

:: أو كلاهما بأمر واحد
npm run build
```

> **ملاحظة:** ملف `MetalCurrencyPrices.exe` الناتج هو تطبيق رسومي حقيقي بلا نافذة سوداء،
> بخلاف تشغيل ملف `.bat` الذي يفتح نافذة أوامر.

## هيكل المشروع

```
Metal&currency-prices/
├─ main.js                     # عملية Electron الرئيسية (نافذة بدون شاشة سوداء)
├─ preload.js                  # جسر آمن بين الواجهة والنظام (contextBridge)
├─ build-package.mjs           # بناء التطبيق الرسومي عبر @electron/packager
├─ build-installer.mjs         # بناء ملف التثبيت عبر Inno Setup
├─ setup.iss                   # سكربت Inno Setup
├─ start.bat                   # تشغيل سريع من المصدر
├─ src/
│  ├─ index.html               # الواجهة (تبويبات + نوافذ الإعدادات/المساعدة)
│  ├─ renderer/
│  │  └─ renderer.js           # منطق الواجهة والاختصارات
│  ├─ styles/
│  │  └─ main.css              # الأوضاع اللونية وأحجام الخطوط
│  └─ services/
│     └─ pricesService.js      # جلب الأسعار + بيانات احتياطية
├─ dist/                       # (مُهمَل من Git) ناتج البناء
└─ Output/                     # (مُهمَل من Git) ملفات التثبيت
```

## مصادر الأسعار

- المعادن (ذهب/فضة): `https://api.gold-api.com/price/{XAU|XAG}`
- أسعار الصرف: `https://open.er-api.com/v6/latest/EGP`

عند تعذّر الاتصال، يستخدم التطبيق بيانات احتياطية تقريبية ويُظهر ذلك في شارة المصدر.
